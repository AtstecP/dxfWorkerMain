# dxfWorker — восстановленный исходный код

Проект восстановлен из `dxfWorker.dll` из `C:\Users\Atstec\Downloads\program\program` декомпилятором Visual Studio. Это реконструкция, а не исходный репозиторий автора.

## Поведение
- Выбирает корневую папку и код детали (`KL`, `UN`, `U`, `T`, `PL` или вручную).
- Копирует `<корень>\<код>\<код> 0` в `<корень>\<код>\<текст из буфера обмена>`.
- Затем удаляет DXF верхнего уровня из исходной папки.
- Добавляет синюю надпись на слой `TextOrder` в DXF верхнего уровня папки назначения и сохраняет копии в `CypCut_<имя папки назначения>`.
- По умолчанию формат DXF — AutoCAD 2004. Хотя в конвертере есть варианты 2007/2010/2013/2018, интерфейс передаёт только путь, поэтому они не выбираются.

## Отличия новой сборки от старой изученной версии
- Поле пути при запуске пустое (раньше была подсказка `Click select folder`).
- Убраны проверка исходного пути и окно с понятной ошибкой; неверный путь может вызвать необработанное исключение.
- Копирование рекурсивное, но удаление исходных DXF и обработка DXF назначения выполняются только на верхнем уровне.

Сборка рассчитана на .NET 6 Windows Forms и использует `lib/netDxf.dll`.
