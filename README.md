# dxfWorker — восстановленный и обновлённый проект

Проект восстановлен из предоставленной сборки `dxfWorker.dll` декомпилятором Visual Studio, затем обновлён по запросу: вместо чтения одного имени из буфера обмена можно ввести несколько имён через `;`.

## Как пользоваться

1. Нажмите **Select folder** и выберите корневую папку, содержащую папки с кодами деталей.
2. Выберите код кнопками `KL`, `UN`, `U`, `T`, `PL` или введите другой код рядом с **Enter**.
3. Введите названия папок, разделяя их точкой с запятой, например `Заказ_1; Заказ_2; Заказ_3`.
4. Нажмите кнопку кода или **Enter**. Для каждого названия создаётся отдельная папка в `<корне>\<код>\<название>`, и в ней появляется подпапка `CypCut_<название>` с обработанными DXF.

Исходные файлы берутся из `<корне>\<код>\<код> 0`. Если целевая папка с одним из имён уже существует, операция останавливается до копирования, чтобы не перезаписывать данные. Повторяющиеся имена игнорируются. После успешной обработки всех вариантов программа, как и исходная сборка, удаляет DXF верхнего уровня из исходной папки.

DXF сохраняется в формате AutoCAD 2004; надпись синяя, размещена на слое `TextOrder`. Файлы во вложенных подпапках копируются, но обработчик DXF рассматривает только файлы верхнего уровня.

Проект собирается под .NET 10 Windows Forms в текущем окружении. Оригинальная сборка была сделана под .NET 6.
