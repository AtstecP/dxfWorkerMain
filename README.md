# dxfWorker — обновлённый проект

## Как пользоваться

1. Нажмите **Выбрать папку**, затем отдельно введите код детали рядом с **Enter** или выберите его кнопкой.
2. Введите названия папок через точку с запятой, например `Заказ_1; Заказ_2; Заказ_3`.
3. Установите максимальную высоту надписи (начальное значение — 12 единиц чертежа).
4. Нажмите кнопку кода или **Enter**. Программа создаст отдельную папку результата для каждого названия и покажет ход обработки. Ошибки и предупреждения появятся в журнале под индикатором; его можно очистить кнопкой «Очистить».

Если программе не удастся найти место под надпись, она спросит, использовать ли старый метод размещения по габаритам чертежа. **Да** продолжает обработку старым способом; **Нет** останавливает её. Старый метод не гарантирует расположение надписи внутри контура, а выбранный максимум ограничивает и его размер.

## Поиск области

Для размещения по контуру программа учитывает линии, дуги, окружности-отверстия, закрытые 2D-полилинии с прямыми сегментами и плоские закрытые 3D-полилинии. Дуги приближаются короткими отрезками; дополнительно проверяются горизонтальные сечения, чтобы находить свободные прямоугольные участки в чертежах со сложными соединениями линий.

Текст подбирается по длине названия и доступной ширине, затем ограничивается настройкой максимальной высоты. Фактическая ширина зависит от SHX-шрифта, поэтому расчёт оставляет запас.

## Исходные файлы

Флажок **«Удалить исходные DXF после успешной обработки»** выключен по умолчанию. Если включить его, исходные DXF верхнего уровня удаляются только после успешной обработки всех указанных названий.

Целевые папки вида `<корень>\<код>\<название>` не перезаписываются, если уже существуют. Файлы из вложенных подпапок копируются, но обработчик рассматривает только DXF верхнего уровня.

Проект собирается под .NET 10 Windows Forms в текущем окружении; исходная программа была собрана под .NET 6.
