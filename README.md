# dxfWorker — восстановленный и обновлённый проект

Проект восстановлен из предоставленной сборки `dxfWorker.dll` декомпилятором Visual Studio и обновлён по запросу.

## Как пользоваться

1. Нажмите **Выбрать папку** и укажите корневую папку, содержащую папки с кодами деталей.
2. Выберите код детали (`KL`, `UN`, `U`, `T`, `PL`) или введите его вручную рядом с **Enter**.
3. Введите названия папок через точку с запятой, например `Заказ_1; Заказ_2; Заказ_3`.
4. Нажмите кнопку кода или **Enter**. Для каждого названия создаётся `<корень>\<код>\<название>\CypCut_<название>`.
5. Индикатор показывает текущий файл, этап и общий процент выполнения. Окно остаётся отзывчивым во время обработки.

Исходные файлы берутся из `<корень>\<код>\<код> 0`. Если папка назначения уже существует, операция останавливается без перезаписи. Повторяющиеся названия удаляются из списка.

Флажок **«Удалить исходные DXF после успешной обработки»** по умолчанию выключен. Если включить его, исходные DXF верхнего уровня удаляются только после успешной обработки всех указанных названий. При ошибке удаления проверьте исходную папку вручную.

DXF сохраняется в формате AutoCAD 2004; надпись синяя, на слое `TextOrder`. Файлы во вложенных подпапках копируются, но обработчик рассматривает только DXF верхнего уровня.

Проект собирается под .NET 10 Windows Forms в текущем окружении. Оригинальная сборка была создана под .NET 6.
