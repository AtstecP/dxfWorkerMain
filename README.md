# dxfWorker — восстановленный и обновлённый проект

Проект восстановлен из предоставленной сборки `dxfWorker.dll` декомпилятором Visual Studio и обновлён по запросу.

## Как пользоваться

1. Нажмите **Выбрать папку** и укажите корневую папку, содержащую папки с кодами деталей.
2. Выберите код детали (`KL`, `UN`, `U`, `T`, `PL`) или введите его вручную рядом с **Enter**.
3. Введите названия папок через точку с запятой, например `Заказ_1; Заказ_2; Заказ_3`.
4. Нажмите кнопку кода или **Enter**. Для каждого названия создаётся `<корень>\<код>\<название>\CypCut_<название>`.
5. Индикатор показывает текущий файл, этап и общий процент выполнения. Окно остаётся отзывчивым во время обработки.

Исходные файлы берутся из `<корень>\<код>\<код> 0`. Если папка назначения уже существует, операция останавливается без перезаписи. Повторяющиеся названия удаляются из списка.

Флажок **«Удалить исходные DXF после успешной обработки»** по умолчанию выключен. Если включить его, исходные DXF верхнего уровня удаляются только после успешной обработки всех указанных названий. При ошибке удаления проверьте исходную папку вручную.

DXF сохраняется в формате AutoCAD 2004; надпись синяя, на слое `TextOrder`. Файлы во вложенных подпапках копируются, но обработчик рассматривает только DXF верхнего уровня.

Проект собирается под .NET 10 Windows Forms в текущем окружении. Оригинальная сборка была создана под .NET 6.

## Активация (ветка `locked-version`)

При первом запуске программа просит код активации. В окне активации показан **ID компьютера** — его сообщает клиент, если код привязывается к конкретному ПК.

### Как сгенерировать код

Код создаётся отдельной утилитой `tools/KeyGen`, которая хранит закрытый ключ (`tools/KeyGen/private.key`). Этот файл и саму утилиту **нельзя передавать клиентам** — он исключён из git (`.gitignore`) и должен существовать только на машине, где выпускаются лицензии.

Первый раз (один раз на всё время, ключ уже создан в этом репозитории):

```powershell
dotnet run --project tools/KeyGen -- init
```

Выпуск кода для клиента:

```powershell
dotnet run --project tools/KeyGen -- gen "Имя клиента" 1y
```

Последняя строка вывода — это код, который нужно отправить клиенту. Клиент вставляет его в окно активации.

Срок действия (третий аргумент):

| Значение | Срок |
|---|---|
| `1m` | 1 минута (для теста) |
| `30d` | 30 дней |
| `1y` | 1 год |
| `2y` | 2 года |

Привязка к одному компьютеру (необязательный четвёртый аргумент — ID компьютера, который показывает клиенту окно активации):

```powershell
dotnet run --project tools/KeyGen -- gen "Имя клиента" 1y A1B2-C3D4-E5F6
```

Без этого аргумента код работает на любом компьютере.

### Публикация готового exe для клиента

```powershell
dotnet publish dxfWorker.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none
```

Результат — один файл `dxfWorker.exe` в `bin\Release\net10.0-windows\win-x64\publish\`, не требующий установки .NET на компьютере клиента.
